# Mapa do Congresso 2027

Esqueleto de site estático (HTML/CSS/JS puro, sem build) com painel de composição e perfis dos parlamentares.

- Abrir: `python3 -m http.server` e acessar http://localhost:8000 (ou abrir `index.html`).
- Dados: `data/dados.js` (**fictícios**). Cada objeto segue as colunas da planilha; só `status: "Aprovado"` aparece.
- Páginas: Panorama, Parlamentares (busca + filtros), Ficha, Sobre, Análises (em construção).
